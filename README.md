# tjsprices-data

Trader Joe's prices for every store, refreshed daily by goddard for
[tjsprices.spencerrego.com](https://tjsprices.spencerrego.com). Generated by
`scripts/sweep-tjsprices.ts` in spencerregodotcom; this branch is force-pushed
as a single commit on every run.

- `stores.json`: `[{ code, name, address }]` for every store with prices.
- `items.json`: `{ fetchedAt, items: { [sku]: { title, size, hasNutrition, imageUrl, url } } }`.
- `stores/<code>.json`: `{ storeCode, fetchedAt, items: [[sku, price, inStock, isNew]] }`.
